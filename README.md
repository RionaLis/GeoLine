# ГеоЛиния

Статический образовательный сайт по геодезии и наукам о Земле. Сборка не требуется: проект можно публиковать на GitHub Pages.

## Публикация на GitHub Pages

1. Загрузите содержимое репозитория в ветку `main`.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.

## Как устроен сайт

- `index.html` — главная страница и описание проекта.
- `encyclopedia.html` — страница «Энциклопедия» (ключевые понятия курсов; статьи готовятся).
- `news.html` — страница «Новости» (раздел готовится).
- `courses/` — папка каждого курса; внутри `index.html` курса и все его уроки.
- `uploads/common/` — общие изображения сайта, включая эмблему.
- `uploads/<название-курса>/` — изображения конкретного курса.

### Общие шаблоны оформления

Единое оформление вынесено в общие файлы — **не задавайте стили шапки, панели, рамки и подвала внутри страниц уроков**:

| Файл | Назначение |
| --- | --- |
| `assets/style.css` | Палитра, шапка и подвал сайта, главная и служебные страницы |
| `assets/lesson-site.css` | Шаблон урока: сетка «боковая панель + поле», зелёная рамка, вкладки, ключевые понятия, единые ширина и типографика |
| `assets/main.js` | Верхняя панель с меню (Главная, Курсы, Энциклопедия, Новости, О проекте), поисковой строкой и подвал. Подключается на **всех** страницах |
| `assets/courses-data.js` | Структура курсов (темы и уроки) — из неё строится боковая панель каждого урока |
| `assets/lesson-blocks.js` | Сборка боковой панели урока и разворачивающихся тем |
| `assets/search-data.js` | Список страниц для поиска |

### Палитра проекта

- `--dark #063f3b` / `--dark2 #07534d` — глубокий зелёный: шапка, подвал, зелёная рамка заголовка урока.
- `--green #0a655d` — зелёный акцентов содержимого.
- `--accent #ff7136` — рыжий: строка «курс · тема» в рамке, активные вкладки, акценты.
- `--paper #f4f8f6`, `--line #d5e3de` — светлый фон и линии.

Семантические цвета интерактива (верно/неверно, классификации, схемы) могут отличаться от основной палитры.

### Структура страницы урока

1. Общая верхняя панель (вставляется `main.js`).
2. Боковая панель: список тем курса с разворачивающимися списками уроков (строится `lesson-blocks.js` из `courses-data.js`).
3. Зелёная рамка заголовка: рыжим — название курса и темы (ссылки на страницу курса), крупно белым — название урока, ниже — тезисы содержания (2–3 строки), затем вкладки навигации по уроку.
4. Под рамкой — горизонтальный список ключевых понятий со ссылками на `encyclopedia.html#термин`.
5. Поле урока фиксированной ширины (`--lesson-w: 1220px`) — одинаковое для всех уроков.

## Как добавить урок

1. Создайте `courses/<курс>/<имя-урока>.html` по образцу соседнего урока:
   - подключите `../../assets/style.css` и `../../assets/lesson-site.css`;
   - на `<body>` укажите `class="gl-lesson" data-root="../.." data-page="courses"`;
   - вставьте `<aside class="gl-sidebar" data-course="<id курса>"></aside>` — панель соберётся автоматически;
   - скопируйте зелёную рамку и строку ключевых понятий из соседнего урока и замените тексты;
   - в конце страницы подключите `search-data.js`, `courses-data.js`, `main.js`, `lesson-blocks.js` (в этом порядке).
2. Зарегистрируйте урок в `assets/courses-data.js` (файл + название в нужной теме).
3. Добавьте строку урока в `index.html` курса (сгруппировано по темам, у каждой темы есть якорь `topic-NN`).
4. Добавьте запись в `assets/search-data.js`.
5. Изображения кладите в `uploads/<название-курса>/` и указывайте путь `../../uploads/<название-курса>/имя-файла.png`.
6. Ключевые понятия добавляйте ссылкой на `../../encyclopedia.html#транслит-термина` и заведите якорь на `encyclopedia.html`.

## Что безопасно менять вручную

Тексты внутри `<h1>`, `<h2>`, `<p>`, `<li>`, содержимое вкладок и интерактивные скрипты уроков. Не удаляйте:

- `data-root` и `data-page` на `<body>`, `data-course` на боковой панели;
- подключения `assets/style.css`, `assets/lesson-site.css`, `assets/courses-data.js`, `assets/main.js`, `assets/lesson-blocks.js`, `assets/search-data.js`;
- классы общей рамки (`gl-lesson-meta`, `gl-meta-nav`, `gl-meta-summary`, `gl-tabs`, `gl-concepts`) — их оформление задаёт `lesson-site.css`.

## Правило хранения файлов

- Общие изображения — в `uploads/common/`, изображения курсов — в `uploads/<название-курса>/`.
- Для каждого курса — отдельная папка внутри `courses/`; главная страница курса — `index.html`.
- Каждая учебная страница хранится в одном экземпляре непосредственно в папке курса.

Пример:

```text
uploads/
  common/
    geoline-logo.png
  geodesy-course-1/
    scheme-01.png
courses/
  geodesy-course-1/
    index.html
    theodolite-horizontal-angles.html
```
