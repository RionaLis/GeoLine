# Учебник по геодезии

Готовый статический учебный сайт для GitHub Pages. Программирование и сборка не требуются.

## Как посмотреть сайт

Откройте файл `index.html` двойным щелчком или опубликуйте репозиторий через GitHub Pages.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **всё содержимое этой папки** в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем **Save**.
6. Через 1–3 минуты GitHub покажет ссылку на сайт.

## Где что находится

- `index.html` — стартовая страница.
- `courses/` — страницы курсов.
- `topics/` — отдельная HTML-страница каждой темы.
- `assets/style.css` — всё оформление.
- `assets/main.js` — общее меню, подвал, мобильная навигация и поиск.
- `assets/search-data.js` — список материалов для поиска.

## Как добавить новую тему

1. Скопируйте любую страницу из `topics/`, например `what-is-geodesy.html`.
2. Переименуйте копию латинскими буквами, например `gnss-methods.html`.
3. Откройте файл в обычном текстовом редакторе и замените заголовки и текст.
4. Добавьте ссылку на тему на нужную страницу в `courses/`.
5. Добавьте тему в `assets/search-data.js`, ориентируясь на существующие записи.

> Важно: не меняйте `data-root=".."` на вложенных страницах — он нужен для правильной работы общего меню.

## Замена названия сайта

Найдите текст `Учебник по геодезии` в `assets/main.js` и HTML-файлах и замените на своё название.
