# ГеоЛиния / GeoLine

Статический образовательный сайт по геодезии и наукам о Земле. Сборка не требуется: проект можно публиковать на GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в него **всё содержимое папки `geodesy-study`**.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.

## Как устроен сайт

- `index.html` — главная страница и описание проекта.
- `courses/` — отдельная папка для каждого курса; внутри находятся страница курса и все его темы.
- `uploads/common/` — общие изображения сайта, включая эмблему.
- `uploads/<название-курса>/` — изображения конкретного курса.
- `assets/style.css` — общее оформление.
- `assets/main.js` — единое меню, подвал и поиск.
- `assets/search-data.js` — список страниц для поиска.

## Как добавлять интерактивную HTML-страницу

Каждая тема хранится **в одном экземпляре** прямо в папке своего курса. Отдельные копии и папка `materials` больше не используются.

1. Сохраните HTML-файл в папку нужного курса, например `courses/geodesy-course-1/new-topic.html`.
2. Подключите к нему `../../assets/lesson-site.css` и добавьте общую верхнюю и нижнюю панели по образцу соседней темы.
3. Добавьте ссылку в `index.html` этого курса.
4. Добавьте запись в `assets/search-data.js`.
5. Изображения темы положите в `uploads/<название-курса>/` и указывайте относительный путь `../../uploads/<название-курса>/имя-файла.png`.

## Какой запрос дать чат-боту

Прикрепите новый HTML-файл и папку сайта либо нужные файлы проекта. Можно использовать такой запрос:

> Добавь приложенный интерактивный HTML-материал в статический сайт «ГеоЛиния». Помести страницу в папку соответствующего курса в одном экземпляре, без iframe, копий и подпапки `materials`; подключи общую рамку сайта по образцу существующих страниц, сохрани единое меню, подвал, навигационную цепочку и автоматическую высоту iframe. Добавь тему в курс «Геодезия. Курс 1», а также в `assets/search-data.js`. Не изменяй работу интерактивной модели. Все ссылки должны работать на GitHub Pages с относительными путями.

Для обычной текстовой темы:

> Создай новую учебную HTML-страницу для сайта «ГеоЛиния» по образцу существующих страниц. Тема: «...». Курс: «...». Сделай понятную структуру с целью темы, теорией, формулами, примером, памяткой и вопросами для самопроверки. Сохрани единое оформление, меню, подвал и относительные ссылки для GitHub Pages. Добавь страницу в курс и поиск.

## Что безопасно менять вручную

Тексты внутри `<h1>`, `<h2>`, `<p>`, `<li>` и названия ссылок. Не удаляйте `data-root=".."`, подключения `assets/style.css`, `assets/main.js` и `assets/search-data.js`: они обеспечивают общее оформление и навигацию.


## Правило хранения файлов

- Общие изображения храните в `uploads/common/`, а изображения курсов — в `uploads/<название-курса>/`.
- Для каждого курса создавайте отдельную папку внутри `courses/`.
- Главная страница курса всегда называется `index.html`.
- Страницы тем хранятся в той же папке курса.
- Каждая учебная HTML-страница хранится в одном экземпляре непосредственно в папке своего курса.

Пример:

```text
uploads/
  common/
    geoline-logo.png
  geodesy-course-1/
    scheme-01.png
courses/
  geodesy-course-1/
    index.html
    theodolite-horizontal-angles.html
```
