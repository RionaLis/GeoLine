ТМОГИ·Тема 02. Основы математической статистики

Предельные теоремы теории вероятностей

Фундаментальный мост между теорией вероятностей и математической статистикой: сущность матстатистики, закон больших чисел Чебышева и Бернулли, центральная предельная теорема Ляпунова как строгое обоснование нормального закона геодезических погрешностей, локальная и интегральная теоремы Муавра-Лапласа.

Разделы

1Предмет и разделы математической статистики

Математическая статистика — раздел математики, посвященный математическим методам систематизации, обработки и использования статистических данных для научных и прикладных задач геодезии.

Сущность математической статистики: по некоторой выборке, если эта выборка является репрезентативной (представительной), сделать объективные выводы о закономерностях, справедливых для всей генеральной совокупности.
1. Описательная статистика

Сжатая характеристика изучаемого явления: таблицы частот, вариационные ряды, графики (полигоны, гистограммы) и числовые характеристики (среднее, дисперсия, СКО, асимметрия, эксцесс).

2. Теория оценивания

Решает задачи оценивания ненаблюдаемых параметров сигналов или объектов на основе выборки (точечные оценки параметров распределения, формулы Гаусса и Бесселя, доверительные интервалы).

3. Теория проверки гипотез

Статистическая процедура, позволяющая на основе выборочных данных сделать строгие математические выводы об обоснованности выдвинутой гипотезы (критерии согласия Пирсона, Стьюдента, Фишера).

Нажимайте на шаги, чтобы последовательно проследить математическое доказательство:

Шаг 1. Физическая модель измерений
Пусть производится n независимых равноточных измерений некоторой величины (угла, расстояния): X₁, X₂, ..., Xₙ.
Все измерения имеют одинаковое математическое ожидание M(Xᵢ) = a (истинное значение без систематических ошибок) и одинаковую дисперсию D(Xᵢ) = σ².
Вычисляется среднее арифметическое: X̄ = (1/n) · (X₁ + X₂ + ... + Xₙ).
Шаг 2. Расчёт математического ожидания и дисперсии среднего арифметического
По свойствам математического ожидания:
M(X̄) = M[(1/n) ∑ Xᵢ] = (1/n) ∑ M(Xᵢ) = (1/n) · (n · a) = a (несмещённость).
По свойствам дисперсии независимых слагаемых константа 1/n выносится в квадрате:
Главный вывод: дисперсия среднего арифметического в n раз меньше дисперсии отдельного измерения!
Шаг 3. Подстановка среднего арифметического в неравенство Чебышева
Применим неравенство Чебышева к случайной величине X̄:
P(|X̄ − a| < ε) ≥ 1 − D(X̄) / ε² = 1 − σ² / (n · ε²).
Здесь величина σ² / (n · ε²) представляет собой максимальную верхнюю границу возможной погрешности оценки.

3Предельная теорема Бернулли и закон больших чисел

Теорема Якоба Бернулли (1713 г.) математически доказала фундаментальное свойство природы — устойчивость относительных частот в массовых случайных экспериментах.

Формулировка теоремы Бернулли: если для результатов многократных независимых испытаний вычислить относительную частоту (частость) Q = k / n (где k — число появлений события A с вероятностью p), то при n → ∞ относительная частота сходится по вероятности к p:

Пошаговый вывод теоремы Бернулли через параметры схемы Бернулли:

Шаг 1. Биномиальное распределение числа успехов k
Случайная величина k (число успехов в серии из n испытаний) имеет биномиальный закон распределения:
• Математическое ожидание: M(k) = np.
• Дисперсия: D(k) = npq, где q = 1 − p.
Шаг 2. Переход к относительной частоте Q = k / n
• Математическое ожидание частости: M(Q) = M(k/n) = M(k)/n = (np)/n = p.
• Дисперсия частости:
С ростом n разброс относительной частоты вокруг истинной вероятности p стремится к нулю обратно пропорционально n.
Шаг 3. Подстановка в неравенство Чебышева
P(|Q − p| < ε) ≥ 1 − D(Q) / ε² = 1 − pq / (n ε²).
При n → ∞ дробь pq / (n ε²) → 0, следовательно, P(|Q − p| < ε) → 1.
Практический вывод: относительная частота появления геодезической погрешности в заданном интервале при неограниченном числе наблюдений строго стремится к теоретической вероятности попадания в этот интервал.

Физический смысл условия: все слагаемые должны быть сопоставимы по величине. Ни одна отдельная погрешность не должна доминировать над остальными.
Шаг 3. Применение к полевым измерениям
Итоговая ошибка измерения направления или расстояния Δ складывается из сотен элементарных независимых причин:
• микронеровности штрихов лимба и оптического клина;
• вибрация грунта и микроколебания штатива;
• турбулентность и температурный градиент приземного слоя атмосферы;
• физиологические погрешности совмещения сетки нитей оператором.
Поскольку каждая из этих причин ничтожно мала, условие Ляпунова выполняется безукоризненно, и суммарная ошибка измерения гарантированно распределена по нормальному закону Гаусса.

1. Контроль знаков погрешностей: при равноточных измерениях вероятность получить положительную ошибку p = 0.5, отрицательную q = 0.5. В серии из 100 приёмов теорема позволяет мгновенно рассчитать допуск на разность числа плюсов и минусов, выявляя скрытый систематический дрейф прибора.
