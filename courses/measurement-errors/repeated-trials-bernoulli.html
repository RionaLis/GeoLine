ТМОГИ·Тема 01. Основы теории вероятностей

Многократные повторные испытания

Схема Бернулли, вероятность ровно m успехов, полезные следствия и вероятнейшее число. От одного испытания — к распределению всей серии.

01 · постановка задачи

Когда серия испытаний становится схемой Бернулли

Мы повторяем один и тот же случайный опыт n раз. В каждом опыте интересующее событие либо произошло — «успех», либо нет — «неуспех».

1
🔁

Одинаковые условия

Каждое испытание проводится по одной методике; вероятность успеха постоянна: p.

2
⛓️‍💥

Независимость

Результат одного испытания не изменяет вероятности результатов остальных.

3
◐

Два исхода

Успех с вероятностью p или неуспех с вероятностью q = 1 − p.

Схема Бернулли — последовательность из n независимых одинаковых испытаний, в каждом из которых событие A наступает с постоянной вероятностью p, а противоположное событие A — с вероятностью q = 1 − p.
✓Подходит: 20 независимых приёмов, вероятность выхода результата за допуск в каждом равна 0,03.
✓Подходит: 10 бросков одной и той же монеты при неизменных условиях.
×Не подходит: извлечение деталей без возврата — состав партии меняется, испытания зависимы.
×Не подходит: наблюдения в быстро меняющуюся погоду — вероятность промаха может быть непостоянной.
Перед применением формулы проверьте не только число опытов, но и независимость и постоянство p. Повторение само по себе ещё не создаёт схему Бернулли.
02 · основная формула

Вероятность ровно m успехов

Пусть событие A должно наступить ровно m раз в серии из n независимых испытаний.

Вероятность одного заданного порядка. Например, AAA̅AA̅ содержит m = 3 успеха и n − m = 2 неуспеха, поэтому по теореме умножения его вероятность равна p³q².

Число возможных порядков. Выбрать позиции для m успехов среди n мест можно Cnm способами.

Складываем несовместные пути. Все порядки имеют одинаковую вероятность, значит, умножаем её на их количество.

Pn(m) = Cnm pm qn−m, Cnm = n!m!(n−m)!
Pn(m)вероятность того, что событие A наступит ровно m раз в n испытаниях
Cnmчисло способов выбрать m позиций успеха среди n испытаний
pвероятность события A в одном испытании
qвероятность противоположного события A в одном испытании; q = 1 − p
nобщее число независимых испытаний
mтребуемое число появлений события A, где 0 ≤ m ≤ n
пример

Два промаха в пяти приёмах

Вероятность промаха в одном приёме p = 0,1. Найдём вероятность ровно двух промахов: n = 5, m = 2, q = 0,9.

P₅(2) = C₅² · 0,1² · 0,9³ = 10 · 0,01 · 0,729 = 0,0729

Обнаружить грубую ошибку

Один независимый контроль выявляет ошибку с вероятностью 0,4. Для трёх контролей вероятность обнаружения хотя бы раз:

1 − (1 − 0,4)³ = 1 − 0,216 = 0,784
интервал

Не более одного отказа

Для 8 приборов вероятность отказа каждого равна 0,05. Событие «не более одного» означает m = 0 или m = 1:

P₈(0) + P₈(1) ≈ 0,6634 + 0,2793 = 0,9428
Типичная ошибка: «хотя бы один» — не то же самое, что «ровно один». Для «хотя бы одного» почти всегда короче считать через противоположное событие.
05 · максимум распределения

Вероятнейшее число успехов

Ищем целое число успехов, которому соответствует наибольшая вероятность в распределении.

Вероятнейшее число успехов k₀ — число появлений события A, при котором вероятность Pn(k) максимальна. Оно определяется из двойного неравенства np − q ≤ k₀ ≤ np + p, где q = 1 − p.
①

Пример: одно значение

При n = 20, p = 0,3, q = 0,7:
5,3 ≤ k₀ ≤ 6,3.
В этом интервале одно целое число: k₀ = 6.

②

Пример: два значения

При n = 9, p = q = 0,5:
4 ≤ k₀ ≤ 5.
Границы целые, поэтому одинаково вероятны k₀ = 4 и k₀ = 5.

Калькулятор вероятнейшего числа

Обратите внимание: интервал от np − q до np + p имеет длину 1. Поэтому внутри него находится либо одно целое число k₀, либо два целых числа на границах — тогда обе вероятности одинаковы.
06 · алгоритм и практика

Как решать задачи без лишних действий

Проверить схему: независимы ли испытания, постоянно ли p, есть ли два взаимоисключающих исхода.

Назначить успех. Им может быть и желательное событие, и отказ, промах, выход за допуск — главное явно определить p.

Перевести слова: «ровно m» → один член; «от a до b» → сумма; «хотя бы один» → 1 − qⁿ.

Подставить и проверить: вероятность должна лежать от 0 до 1; округлять лучше в самом конце.

задача 1 · геодезия

Ровно один выход за допуск

Вероятность выхода отдельного измерения за допуск равна 0,02. Выполнено 10 независимых измерений.

P₁₀(1) = C₁₀¹·0,02·0,98⁹ ≈ 0,1667
задача 2 · контроль

Хотя бы один дефект

Вероятность дефекта пункта сети — 0,01. Проверяют 50 независимых пунктов.

P(m ≥ 1) = 1 − 0,99⁵⁰ ≈ 0,3950
задача 3 · интервал

От двух до четырёх сигналов

Сигнал принимается с вероятностью 0,7; выполняют 6 независимых сеансов.

P(2≤m≤4) = P₆(2)+P₆(3)+P₆(4) ≈ 0,5689
задача 4 · режим

Вероятнейшее число успехов

Для 30 наблюдений вероятность успеха p = 0,8, поэтому q = 1 − p = 0,2. Используем формулу вероятнейшего числа:

np − q ≤ k₀ ≤ np + p
30·0,8 − 0,2 ≤ k₀ ≤ 30·0,8 + 0,8
23,8 ≤ k₀ ≤ 24,8
k₀ = 24
Граница применимости. Формула Бернулли точна, но при очень больших n вычислять факториалы неудобно. Тогда используют приближения Пуассона или Муавра—Лапласа — это продолжение темы.
