ТМОГИ·Тема 01. Основы теории вероятностей

Закон распределения дискретной случайной величины

Случайная величина и её закон распределения. Три способа задания закона для дискретной величины: ряд распределения, многоугольник распределения и функция распределения. Свойства функции распределения и вероятность попадания в интервал — с интерактивными примерами и приложениями в геодезии.

Разделы

1Случайная величина и закон распределения

Свяжем со случайным опытом число и научимся описывать сразу все его возможные значения вместе с их вероятностями.

Случайная величина — величина, которая обладает некоторым множеством возможных значений, причём заранее нельзя предсказать, какое именно значение она примет в результате того или иного испытания.

В отличие от постоянной величины случайную величину недостаточно характеризовать только числовыми значениями — надо знать ещё и вероятности появления этих значений. Случайные величины обозначают заглавными буквами X, Y, Z, а их значения — соответственно x1, x2, …, xn.

Пример. При подбрасывании игральной кости случайная величина X — число выпавших очков — принимает значения 1, 2, 3, 4, 5, 6, каждое с вероятностью 1/6. Любое событие можно описать случайной величиной: бросая монету, присвоим «решке» значение 1, «орлу» — 0; каждое значение имеет вероятность 1/2.
Закон распределения случайной величины — всякое соотношение, устанавливающее связь между значениями случайной величины и вероятностями появления этих значений. Поведение случайной величины полностью определяется её законом распределения.

1.1Дискретные и непрерывные величины

🎲
Дискретная (прерывная)

Множество значений не более чем счётно (эквивалентно множеству натуральных чисел). Значения можно перечислить: 0, 1, 2, …

📏
Непрерывная

Все значения заполняют отрезок числовой оси. Множество значений бесконечно и несчётно — перечислить их нельзя.

Связь с геодезией. К дискретным случайным величинам относится, например, число положительных (или отрицательных) ошибок измерений в геодезических сетях. Сами же ошибки измерений — это непрерывные случайные величины. Этот урок посвящён дискретному случаю; непрерывным величинам посвящён следующий урок.

Для дискретной величины все возможные значения образуют полную группу несовместных событий, поэтому сумма их вероятностей равна единице:

P1 + P2 + … + Pn = ∑ Pi = 1.

2Ряд распределения

Первый и самый наглядный способ задания закона распределения дискретной величины.

Ряд (таблица) распределения — таблица, устанавливающая соответствие между значениями случайной величины xi и вероятностями появления этих значений pi.
Xx1x2…xn
Pp1p2…pn

Так как все значения X образуют полную группу несовместных событий, вероятности ряда обязаны удовлетворять условию нормировки ∑ pi = 1. Это первое, что нужно проверять у любого ряда распределения.

Пример. Произведено одно измерение. Пусть X — число появлений положительной ошибки: оно равно либо 0, либо 1, то есть X = (0; 1). Тогда при p1 + p2 = 1 ряд распределения принимает вид: X = 0 → P = 0,5; X = 1 → P = 0,5.

3Многоугольник распределения

Второй способ задания закона распределения — графический.

Многоугольник распределения — ломаная линия, построенная по ряду распределения: по оси абсцисс откладывают все возможные значения случайной величины xi, по оси ординат — вероятности их появления pi, а полученные точки последовательно соединяют отрезками.
Пример. Многоугольник распределения строится для ряда: X = (−5; −3; 2; 7), P = (0,1; 0,4; 0,3; 0,2). Наибольшая ордината приходится на значение −3 с вероятностью 0,4.

📐 Построение многоугольника

По оси абсцисс — значения xi, по оси ординат — вероятности pi; точки соединены ломаной.

4Функция распределения F(x)

Третий, самый универсальный способ: одна функция задаёт закон распределения и дискретной, и непрерывной величины.

Функция распределения F(x) — вероятность того, что случайная величина X примет значение, меньшее некоторого числа x:
F(x) = P(X < x).
Геометрически это вероятность попадания значений случайной величины на числовую прямую левее точки x, причём сама точка x в этот интервал не входит — неравенство строгое (X < x). Для дискретной величины F(x) равна сумме вероятностей всех значений, лежащих строго левее x.
Пример. Для ряда распределения X = (−5; −3; 2; 7), P = (0,1; 0,4; 0,3; 0,2) найдём значения функции распределения в точках существования величины и добавим их третьей строкой в таблицу:
X−5−327
P0,10,40,30,2
F(X)00,10,50,8
Каждое значение F получается суммированием вероятностей всех значений, лежащих строго левее:
F(−5) = P(X < −5) = 0
F(−3) = P(X < −3) = P(−5) = 0,1
F(2) = P(X < 2) = P(−5) + P(−3) = 0,1 + 0,4 = 0,5
F(7) = P(X < 7) = P(−5) + P(−3) + P(2) = 0,1 + 0,4 + 0,3 = 0,8
В произвольной точке значение F совпадает с накопленной суммой слева: например F(−1) = P(X < −1) = P(−5) + P(−3) = 0,1 + 0,4 = 0,5.

График функции распределения дискретной величины — ступенчатый: он терпит разрывы в точках существования случайной величины, причём величина скачка равна вероятности появления данного значения. В точке разрыва функция принимает меньшее значение (левое), а большее показывают выколотой точкой. Слева от наименьшего значения график идёт по оси абсцисс (F = 0) и уходит в область отрицательных x; справа от наибольшего значения — на уровне F = 1.

Пример: построение F(x) для биномиального распределения. Пусть X — число появлений события в n = 4 независимых испытаниях при p = 0,5 (например, число положительных ошибок в четырёх измерениях). Вероятности по формуле Бернулли P4(k) = C4k·0,54 и накопленные значения F(k) = P(X < k):

5Свойства функции распределения

Функция распределения обладает тремя основными свойствами — они одинаковы для дискретных и непрерывных величин.

Свойство 1. F(−∞) = 0. При x → −∞ вероятность попасть левее уходящей влево точки стремится к нулю. В частном случае, если X сосредоточена на отрезке [A, B], то F(A) = 0: попасть левее отрезка нельзя.
Свойство 2. F(+∞) = 1. Все значения величины лежат в пределах от −∞ до +∞, поэтому вероятность оказаться левее уходящей вправо точки стремится к единице. Если X ∈ [A, B], то для любого ε > 0 весь отрезок окажется левее точки B + ε, то есть F(B + ε) = 1.
Свойство 3. F(x) — неубывающая функция: если x2 > x1, то F(x2) ≥ F(x1). Область «левее x2» полностью накрывает область «левее x1», поэтому F(x1) = P(X < x1) не может быть больше F(x2) = P(X < x2).
Три области графика. В общем случае график F(x) имеет три области: (1) левее области существования величины — совпадает с осью абсцисс (F = 0); (2) область значений величины — здесь F(x) растёт до единицы; (3) правее — все значения F(x) равны единице. Это справедливо и для дискретных, и для непрерывных величин.

6Вероятность попадания в интервал

Главная практическая формула: вероятность попадания в интервал выражается через функцию распределения.

Пусть событие A — появление значений X левее точки x1 (X < x1), событие B — появление значений левее x2 (X < x2), а событие C — попадание на отрезок x1 ≤ X < x2. События A и C несовместны и в сумме дают B, поэтому P(B) = P(A) + P(C). Отсюда:

P(x1 ≤ X < x2) = F(x2) − F(x1).
Важно. В отрезок x1 ≤ X < x2 левая точка x1 включена, а правая x2 не включена — это прямое следствие определения F(x) = P(X < x).

6.1Почему один конец включён, а другой — нет

Разность F(x2) − F(x1) — это вычитание из «широкого» события B = {X < x2} «узкого» события A = {X < x1}. Наглядно это два перекрывающихся интервала (лучи влево), а искомый отрезок C — то, что от них остаётся:

6.2Как включить или исключить нужный конец

Для дискретной величины передвижение или включение конца меняет результат ровно на вероятность значения в этой точке P(X = xi). Отсюда четыре варианта:

ИнтервалФормула через F(x)
x1 ≤ X < x2 (левый включён, правый нет — базовая)F(x2) − F(x1)
x1 ≤ X ≤ x2 (включить правый конец)F(x2) − F(x1) + P(X = x2)
x1 < X < x2 (исключить левый конец)F(x2) − F(x1) − P(X = x1)
x1 < X ≤ x2 (исключить левый, включить правый)F(x2) − F(x1) − P(X = x1) + P(X = x2)
Если конец не совпадает ни с одним значением величины, то P(X = конец) = 0, и тогда включать его или нет — безразлично: результат не меняется.
Примеры (ряд X = (−5; −3; 2; 7), P = (0,1; 0,4; 0,3; 0,2)):
  • P(−5 ≤ X < 2) = F(2) − F(−5) = 0,5 − 0 = 0,5. То же как сумма: P(−5) + P(−3) = 0,1 + 0,4 = 0,5.
  • P(−3 ≤ X < 7) = F(7) − F(−3) = 0,8 − 0,1 = 0,7. То же как сумма: P(−3) + P(2) = 0,4 + 0,3 = 0,7.
Итак, вероятность попадания на отрезок — это и разность значений F в крайних точках, и сумма вероятностей всех значений, попавших в интервал.
