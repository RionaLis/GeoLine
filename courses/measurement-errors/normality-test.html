ТМОГИ·Тема 02. Основы математической статистики

Проверка на нормальность распределения

Статистическая проверка гипотезы о нормальном законе распределения геодезических измерений: нестрогие критерии по точечным оценкам числовых характеристик, вариационный ряд и гистограмма частот, выравнивающая кривая Гаусса и строгий критерий согласия Пирсона χ².

Разделы

1Понятие статистической гипотезы и критерия согласия

В геодезии классические формулы оценки точности (Гаусса, Бесселя, весов метода наименьших квадратов) строго справедливы только при нормальном законе погрешностей. Поэтому проверка соответствия выборочных данных нормальному закону является обязательным этапом контроля полевых работ.

Статистическая гипотеза H₀: предположение о том, что генеральная совокупность погрешностей подчиняется нормальному закону N(a, σ²).
Критерий согласия: статистическое решающее правило, по которому гипотеза H₀ принимается или отвергается на основе выборочной меры расхождения между эмпирическим и теоретическим распределениями.
Уровень значимости α: малая вероятность отвергнуть верную нулевую гипотезу (ошибка 1-го рода). Обычно в геодезии принимают α = 0.05 (5%) или α = 0.01 (1%).

Точечные оценки

Вычисление выборочных среднего, СКО, среднего абсолютного отклонения, асимметрии и эксцесса. Проверка по нестрогим признакам.

Расчёт меры расхождения Пирсона, определение числа степеней свободы и строгое сравнение с критической границей χ²_табл.

Критерии проверки

1. Проверка на наличие систематической погрешности

В ряде истинных случайных погрешностей математическое ожидание строго равно нулю ($M[\Delta] = 0$). Выборочное среднее Δ̄ не должно статистически значимо отличаться от нуля по критерию Стьюдента:

Для геодезической выборки объема n = 48, Δ̄ = -0,14, m = 2,27 при t_α = 2,5:
Неравенство соблюдено: 0,14 ≤ 0,82.
Систематическая составляющая в измерениях отсутствует. Для дальнейшей обработки математическое ожидание обоснованно принимается равным нулю ($a = M[\Delta] = 0$).

2. Проверка на нормальность распределения (критерий Гаусса)

Для закона Гаусса среднее абсолютное отклонение Δ̄* связано со средней квадратической ошибкой σ* строгим теоретическим соотношением Δ̄ = σ√(2/π) ≈ 0,80 σ:

По данным выборки n = 48 получено Δ̄* = 1,61, σ* = 2,09:
Отношение Δ̄* / σ* = 1,61 / 2,09 ≈ 0,77, расхождение с 0,80 составляет всего 0,06 (3,7%).
Соотношение Гаусса выполняется с высокой точностью; форма опытного распределения согласуется с нормальным законом.

3. Проверка на симметрию

Нормальная кривая строго симметрична, поэтому все нечётные центральные моменты равны нулю (μ3 = 0), а теоретический коэффициент асимметрии Sk = 0. Выборочный коэффициент асимметрии не должен превышать утроенной ошибки выборочной асимметрии:

По выборке n = 48 получено μ3* = -3,78, Sk* = -0,41, σ_Sk = √(6/48) ≈ 0,35:
Неравенство выполнено: |-0,41| = 0,41 ≤ 1,05.
Выборочная асимметрия незначима и обусловлена случайными колебаниями выборки. Гипотеза о симметрии ошибок принимается.

4. Проверка на нормальность крутизны

Для распределения Гаусса отношение μ4 / σ^4 = 3, поэтому теоретический эксцесс E = 0. Выборочный эксцесс E* не должен выходить за доверительный диапазон 3σ_E:

По выборке n = 48 получено μ4* = 59,91, E* = +0,14, σ_E = √(24/48) ≈ 0,71:
Неравенство выполнено: |+0,14| = 0,14 ≤ 2,13.
Эксцесс статистически равен нулю; вершина эмпирического распределения имеет нормальную островершинность.

Линейное интерполирование для значения χ²_расч = 6,58 при r = 10:

Значение χ²_расч = 6,58 заключено между табличными узлами χ1² = 6,18 (P1 = 0,80) и χ2² = 7,27 (P2 = 0,70):

P(χ² > 6,58) = 0,80 + [(0,70 - 0,80) / (7,27 - 6,18)] · (6,58 - 6,18) = 0,80 - (0,10 / 1,09) · 0,40 = 0,80 - 0,037 = 0,763 ≈ 0,76 (76%)

Вывод: Достигнутый уровень значимости P = 0,76 значительно превосходит критический уровень α = 0,10 (P >> α), а расчётное значение χ²_расч = 6,58 < 15,99. Гипотеза о нормальном распределении погрешностей измерений безусловно принимается!
