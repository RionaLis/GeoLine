Вероятность попадания в интервал

Вычисление вероятности попадания случайной величины в заданный интервал: логическое построение через интеграл Ньютона — Лейбница, две формы функции Лапласа Ф₀(t) и Ф(t), эталонные таблицы значений, расчётные примеры и правило трёх сигм.

Так как между множествами значений X и T установлено строгое линейное взаимно-однозначное соответствие, искомая вероятность сохраняется неизменной:

Шаг 4. Почему интеграл нельзя взять аналитически

Поэтому математики составили универсальные таблицы значений этой функции от одного аргумента t, которые занимают всего одну страницу и позволяют мгновенно находить точные вероятности для любых геодезических приборов.

2Две формы функции Лапласа и связь с функцией распределения

В научной и геодезической литературе исторически используются две формы специальной функции нормального распределения — полуинтервальная Ф₀(t) и интеграл вероятностей Ф(t).

Форма 1. Полуинтервальная функция Лапласа Ф₀(t)

Задаёт вероятность попадания стандартной величины в полуинтервал от центра 0 до точки t. В нуле строго равна 0: Ф₀(0) = 0, на бесконечности Ф₀(+∞) = 0.5.

Форма 2. Удвоенный интеграл вероятностей Ф(t)

Задаёт вероятность попадания в симметричный относительно центра интервал [−t; +t]. В нуле Ф(0) = 0, на бесконечности Ф(+∞) = 1.0.

Логическая связь функции распределения F(t) и функции Лапласа:

Функция распределения F(t) представляет собой интеграл от −∞ до t. Разобьём его в точке нуля на сумму двух интегралов:

1. Нечётность функции Лапласа: Ф₀(−t) = −Ф₀(t) и Ф(−t) = −Ф(t).
Это следует из чётности подынтегральной колоколообразной функции exp(−z²/2).
Практическое следствие: таблицы достаточно составлять только для положительных t > 0. При отрицательных границах берётся то же табличное значение, но со знаком «минус».
2. Асимптотические пределы:
Ф₀(+∞) = 0.5, Ф₀(−∞) = −0.5.
Ф(+∞) = 1.0, Ф(−∞) = −1.0.
Уже при t ≥ 3.5 значение Ф(t) ≈ 0.9995 практически неотличимо от единицы (вся масса случайных погрешностей сосредоточена в полосе ±3.5σ).

Пример 1. Вероятность положительной ошибки измерения угла
Измерения горизонтального угла характеризуются СКО σ = 10" и отсутствием систематических смещений (a = M(Δ) = 0).
Какова вероятность того, что случайная погрешность угла окажется положительной и не превысит 10"?
• Нормированные границы: t₁ = (0 − 0)/10 = 0; t₂ = (10 − 0)/10 = 1.0.
• По таблице: Ф₀(0) = 0; Ф₀(1.0) = 0.3413.
• Результат: P(0" < Δ < 10") = 0.3413 − 0 = 34.13%.
А вероятность того, что ошибка в целом будет меньше 10" (включая все отрицательные): P(Δ < 10") = F(1.0) = 0.5 + 0.3413 = 0.8413 (84.13%).
Пример 2. Симметричный интервал погрешности
В тех же условиях определить вероятность того, что ошибка измерения угла по модулю не превысит 10" (|Δ| ≤ 10"):
• Это симметричный интервал [−10"; +10"] с t = 1.0.
• По таблице симметричной функции: Ф(1.0) = 2 · Ф₀(1.0) = 2 · 0.3413 = 0.6827.
• Результат: ровно 68.27% всех измеренных углов будут лежать в коридоре ±10".
Пример 3. Измерение линии светодальномером с систематической ошибкой
Длина линии измеряется светодальномером с СКО σ = 5 см. Прибор имеет систематическую ошибку калибровки a = M(Δ) = +1 см.
Какова вероятность того, что фактическая ошибка не превысит по абсолютной величине 10 см (|Δ| ≤ 10 см, т.е. −10 ≤ Δ ≤ 10)?
• Нормированные границы:
t₁ = (−10 − 1) / 5 = −11 / 5 = −2.20
t₂ = (+10 − 1) / 5 = +9 / 5 = +1.80
• По таблице: Ф₀(1.80) = 0.4641; Ф₀(−2.20) = −Ф₀(2.20) = −0.4861.
• Вероятность: P(−10 ≤ Δ ≤ 10) = 0.4641 − (−0.4861) = 0.4641 + 0.4861 = 0.9502 (95.02%).
(Из-за систематического смещения в +1 см вероятность слегка снизилась по сравнению с идеальными 95.45%).

Математический расчёт показывает:
Вероятность появления ошибки, превышающей 3σ, равна всего 0.27% (меньше 3 раз на 1000 измерений).
В метрологии и практической геодезии событие с вероятностью менее 0.003 принимается за практически невозможное. Поэтому при появлении погрешности свыше 3σ твёрдо считается, что произошёл сбой прибора, сдвиг вехи или просчёт оператора. Измерение бракуется без права включения в уравнивание и выполняется повторный приём.
