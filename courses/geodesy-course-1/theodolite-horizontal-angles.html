Принцип измерения горизонтальных углов теодолитом

Интерактивная модель · Станция B, левая цель C, правая цель A · β = a − c · полный приём КЛ + КП

1В чём суть измерения

Горизонтальным углом называют горизонтальную проекцию угла, образованного точками местности, на уровенную поверхность.

При визировании на цель берут отсчёт по лимбу горизонтального круга, который покажет направление на цель относительно нуля лимба. Если при одной и той же установке прибора взять по отсчёту на две цели, то по разности между отсчётами можно вычислить горизонтальный угол между этими целями.

Теодолит устанавливают в вершине угла — на станции B (над колышком, закреплённым в земле). На концах сторон угла выставляют вехи: C — левая цель, A — правая цель.

Внутри теодолита находится лимб — горизонтальный круг с делениями 0…360°. Наводя трубу поочерёдно на цели, снимают отсчёты по лимбу через отсчётный микроскоп:

β = a − c a — отсчёт на правую цель A, c — отсчёт на левую цель C.
Если a < c, то β = a − c + 360°
  • Измеряется не пространственный угол между визирными лучами, а угол между их проекциями на горизонтальную плоскость;
  • Угол по лимбу отсчитывается по ходу часовой стрелки — от левой цели к правой;
  • Наводить трубу нужно на низ вехи — так меньше ошибка от её наклона.

Горизонтальный круг (лимб) — вид сверху: отсчёты c и a показаны дугами от нуля лимба до соответствующих целей; β = a − c.

2Порядок измерения горизонтального угла полным приёмом

  1. Приведение в рабочее положение:
    Центрирование прибора — установка вертикальной оси прибора над вершиной измеряемого угла.
    Горизонтирование прибора — приведение вертикальной оси прибора в отвесное положение с помощью подъёмных винтов и цилиндрического уровня.
  2. Первый полуприём (КЛ) — при положении круг лево наводят на правую цель A, берут отсчёт a₁ по микроскопу и записывают в журнал; затем на левую C — отсчёт c₁. Вычисляют угол полуприёма β′ = a₁ − c₁.
  3. Между полуприёмами — трубу переводят через зенит (теперь положение круг право) и сбивают лимб на 1–2°, чтобы отсчёты второго полуприёма пришлись на другие штрихи лимба.
  4. Второй полуприём (КП) — при положении круг право повторяют: отсчёт a₂, затем c₂; вычисляют β″ = a₂ − c₂.
  5. Контроль и результат — расхождение |β′ − β″| ≤ 2t (двойная точность отсчёта); β = (β′ + β″) / 2.

Отсчёты и углы полуприёмов — до целой минуты; до 0,1′ (…,0 или …,5) записывается только среднее. В примере расхождение между полуприёмами составило 2′ — на пределе допуска (2t = 2′), приём принят.

Зачем два полуприёма? Измерение при КЛ и КП исключает влияние коллимационной ошибки и наклона оси вращения трубы, а сбивка лимба между полуприёмами ослабляет ошибки его делений. Отсчёты при КП отличаются от КЛ примерно на 180° (плюс сбивка лимба) — это нормально: угол β от этого не меняется.

КЛ — положение круг лево Ориентировка лимба устанавливается случайно при приведении прибора в рабочее положение и сбивается на 1–2° при переходе к КП.

Вехи C и A можно перетаскивать мышью. При снятии отсчётов моделируются случайные погрешности наблюдателя, изредка — грубый промах. Голубые пунктирные линии на земле — проекции визирных лучей на горизонтальную плоскость; между ними — измеряемый угол β.

5Главное, что нужно запомнить

  • Сначала — центрирование по отвесу над колышком и горизонтирование по уровню, только потом измерения.
  • Горизонтальный угол — это угол между проекциями визирных лучей на горизонтальную плоскость.
  • Угол получается как разность двух отсчётов: β = a − c (правая цель минус левая); если a < c — прибавляем 360°.
  • Наводить трубу — на низ вехи, биссектором сетки нитей.
  • Полный приём = полуприём при КЛ + полуприём при КП; между ними трубу переводят через зенит и сбивают лимб на 1–2°.
  • Контроль: |β′ − β″| ≤ 2t; результат — среднее из двух полуприёмов.
  • У серии Т30 отсчёты берутся до целой минуты; до 0,1′ (…,0 или …,5) вычисляется только среднее значение угла.
